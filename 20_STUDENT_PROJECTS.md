# ZEBJUS Python Lab v5.12 — 20 Student Projects

These projects are designed for students to type, modify, run, and debug.
Legacy transport code such as `SerialModule`, `SerialObject`, `arduino.sendData()`, `WifiBridge`, and `HandTrackingModule` is not used in these 20 examples.

5. **RGB LED Colors** — `examples/05_rgb_led_colors.py`

## Teaching order

- Projects 1–4: Python basics
- Projects 5–10: ZEBJUS hardware API / simulation
- Projects 11–13: OpenCV image processing
- Projects 14–16: Face AI
- Projects 17–20: Hand AI and gesture control

Image projects use manual upload paths such as `uploads/test.jpg`.
